# 噜噜健康助手（lulu-bmi）

**给怕被说教的普通人，一个敢每天打开的体重管理工具。**

水豚「噜噜」陪你记录体重与 BMI，算清 BMR/TDEE，给出一周餐谱和运动计划——数据只存在你自己的设备上，不注册、不登录、不上传。

## 项目背景

很多体重管理工具的问题不是功能不够，而是让人不敢打开：打开就是红色警告、严厉目标、KPI 式打卡。噜噜健康助手面向的正是**被工具说教怕了的人**——包括正在和进食障碍相处、看到体重数字就有压力的人：

- 语气上：噜噜只陪伴、不评判。「今天想称体重吗？没有也没关系」；
- 机制上：记录一周 2–3 次就够，腰围选填、没量就不参与评估；
- 安全上：内置进食障碍筛查，命中后可以**把体重数字整个收起来**，只看趋势方向，记录照常能记；
- 隐私上：所有数据写在本机 localStorage，清空浏览器数据前可以先导出备份。

## 核心功能

以下全部来自代码实现，无虚构：

**今日仪表盘**
- 按时段变化的噜噜问候 + 体重主路径输入，BMI、腰围、体重数字实时回显
- 实测腰围选填（校验区间 50–150 cm），一个月量一次即可；历史记录支持后补腰围
- 记录流水备注、按日期删除，趋势文字小结与上周对比

**健康评估与目标**
- BMI 分级采用**中国成人标准（WS/T 428-2013）**，带标准刻度条
- BMR 按 **Mifflin-St Jeor 公式**计算，进而推 TDEE 与热量缺口
- 目标三选一：慢慢减重 / 慢慢增重 / 维持；周变化标称值有保护上限，热量下限兜底不低于 BMR
- 腰围按性别判定中心性肥胖 / 前期（男 ≥90 cm、女 ≥85 cm）

**安全筛查（先于方案）**
- **病史初筛 4 题**：怀孕/备孕/哺乳、基础病（糖尿病/高血压/心脏病/甲状腺/肝肾）、影响体重的药物、近 3 个月体重无故变化超 5%
- 高风险 → 拦截卡「噜噜今天先不给你方案」，引导先看医生，但体重记录照常可用；之后答应用户更新答案、风险降级会自动恢复完整界面（不丢数据）
- 中风险 → 方案照给但标注提醒
- **进食障碍筛查**：命中后可隐藏体重数字、只显示趋势方向，并给出专业求助指引
- 运动前安全检查：跌倒史、关节问题等，命中后自动换低冲击动作

**7 天饮食方案**
- 按目标热量出 7 天餐谱，支持「换一批」轮换
- 忌口替换：素食、海鲜过敏、乳糖不耐、不吃辣等标签，命中自动换菜
- 自定义菜品、按餐勾选打卡
- **真实场景应急方案**：聚餐、外卖等场景的应对建议，支持改写成自己的话

**一周运动计划**
- 有氧 + 力量组合，剂量按目标分档（健康成人 150–200 min/周中等强度有氧，减脂 200–300，超重/肥胖 ≥250 且只推低冲击动作）
- 久坐新手渐进：第 1 周只要求每天走 10 分钟，走满一周再进标准计划
- 运动偏好自选（喜欢的有氧/力量、要排除的项目），步数目标单独列出

**每日打卡与激励**
- 早/午/晚/加餐/运动逐项打卡，连续天数 streak、本周打卡率
- 达成目标时的庆祝动画

**数据与隐私**
- JSON 备份导出/导入、CSV 流水导出、分享文案一键复制
- localStorage 写满时提前预警并引导备份，不静默丢数据
- 一键清空全部本机数据

**就医提示**
- 「监测与复查」「何时就医」两节通用提示，并明确声明不能替代医生面诊

## 技术亮点

- **单文件 PWA**：HTML/CSS/JS 全部内联在一个 `index.html`（约 534 KB）里，零框架、零依赖、零构建步骤
- **Service Worker 离线可用**：应用外壳预缓存；页面导航 network-first（有网拿新版、断网用缓存），发版靠缓存版本号（当前 `lulu-bmi-v25`）强制淘汰旧缓存
- **localStorage 多键管理**：约 20 个键统一注册在 `STORE` 表中；读写全部走 `safeGet/safeSet` 容错封装，对手工改坏、旧版残留、写到一半断电留下的脏数据有形状校验和兜底
- **防御式数据处理**：导入备份、历史记录补写等入口都有 `isPlainObj/asArray` 形状清洗，避免 `.toFixed()` 之类的运行时崩溃
- **可安装到手机桌面**：manifest + 普通/遮罩双图标，standalone 独立窗口运行
- **质量保障**：1600+ 条 jsdom 自动化测试断言与多阶段用户旅程探针（多画像旅程、数据往返、脏数据、边界输入）

## 项目结构

| 文件 | 职责 |
|---|---|
| `index.html` | 全部页面结构、样式与逻辑（CSS/JS 内联），约 534 KB |
| `sw.js` | Service Worker：预缓存外壳、离线回退、旧缓存清理 |
| `manifest.webmanifest` | PWA 清单：名称、主题色、图标、standalone 模式 |
| `icon.svg` | 应用图标（任意场景） |
| `icon-maskable.svg` | 遮罩安全区图标（Android 自适应图标） |

## 如何运行与部署

**本地运行**：双击 `index.html` 即可在浏览器打开（离线功能与 PWA 安装需通过 HTTPS 部署后体验）。

**GitHub Pages**：仓库 `hj114125/lulu-bmi`，`index.html` 位于 main 分支根目录，开启 Pages（Settings → Pages → Source 选 `main` 分支 `/ (root)`）后访问：

> **https://hj114125.github.io/lulu-bmi/**

**部署为 PWA 的注意点**：每次更新 `index.html` 后必须同步递增 `sw.js` 里的 `CACHE` 版本号，否则老用户会一直命中旧缓存。

**任意静态托管**：把 5 个文件原样放到站点根目录即可，无需任何服务端。
